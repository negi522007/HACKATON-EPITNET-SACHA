# EPITNET 2026 - AI & Web Generation Engine

This project is developed for the EPITNET 2026 Hackathon, organized by EPITECH Afrique and ITNET Technologies. It is an automated solution designed to generate and instantly deploy optimized showcase websites from a single text prompt.

## Core Pillars

Our approach relies on the synergy of three main technical components:

* **AI Generation**: Interpretation of user requirements to instantly produce textual content and structure for the showcase site.
* **Template Engine**: Automatic assembly of the generated data into a clean, modern, and responsive web interface.
* **DevOps Pipeline**: Complete automation of the build and continuous deployment (CI/CD) process to the Wayhost cloud infrastructure.
